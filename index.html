电商用户行为数据分析

数据模型（3 张表）

  • user_info 用户表 · 200 行 —— 注册日期 / 城市 / 获客渠道

指标拆解

月度 GMV 趋势

折线展示 13 个月 GMV 波动；6 月（618）与 11 月（双11）明显冲高，验证促销周期对成交的影响。
查看 SQL 
SELECT DATE_FORMAT(order_date, '%Y-%m') AS ym,
       ROUND(SUM(amount)/10000, 2) AS gmv_wan
FROM order_info
WHERE is_paid = 1
GROUP BY DATE_FORMAT(order_date, '%Y-%m')
ORDER BY ym;

转化漏斗

浏览 → 加购 → 下单 → 支付；数「人」用 COUNT(DISTINCT)，不能按步骤 GROUP BY。
查看 SQL 
SELECT event_type,
       COUNT(DISTINCT user_id) AS uv,
       COUNT(*) AS events
FROM user_event
GROUP BY event_type
ORDER BY FIELD(event_type, 'view', 'cart', 'order', 'pay');

用户留存曲线（次日 ~ 7日）

注册后第 N 天仍活跃的用户占比，逐日衰减，是衡量用户粘性的核心指标。
查看 SQL 
-- 次日留存率 = 注册次日仍活跃的去重用户数 / 注册用户总数
-- 将 DATEDIFF(...)=1 换成 1..7 逐天计算，即得留存曲线
SELECT ROUND(COUNT(DISTINCT CASE
            WHEN DATEDIFF(DATE(b.event_time), a.register_date) = 1
            THEN a.user_id END)
       / COUNT(DISTINCT a.user_id) * 100, 1) AS day1_retention_pct
FROM user_info a
LEFT JOIN user_event b ON b.user_id = a.user_id;

品类 GMV 占比

数码类贡献最高；占比用窗口函数 SUM(...) OVER() 一次算出，无需二次查询。
查看 SQL 
SELECT category,
       ROUND(SUM(amount)/10000, 2) AS gmv_wan,
       ROUND(SUM(amount) / SUM(SUM(amount)) OVER (), 4) AS pct
FROM order_info
WHERE is_paid = 1
GROUP BY category
ORDER BY gmv_wan DESC;

新老客 GMV 拆分

用 ROW_NUMBER() 按用户首单标记新客（rn=1）与老客，老客贡献更高。
查看 SQL 
WITH ranked AS (
  SELECT user_id, amount,
         ROW_NUMBER() OVER (PARTITION BY user_id
                            ORDER BY order_date, order_id) AS rn
  FROM order_info WHERE is_paid = 1
)
SELECT CASE WHEN rn = 1 THEN '新客' ELSE '老客' END AS cust_type,
       ROUND(SUM(amount)/10000, 2) AS gmv_wan
FROM ranked
GROUP BY cust_type;

近 30 天 DAU 趋势

按日去重活跃用户数；周末明显抬升，工作日回落，呈现典型的电商活跃节奏。
查看 SQL 
SELECT DATE(event_time) AS dt, COUNT(DISTINCT user_id) AS dau
FROM user_event
GROUP BY DATE(event_time)
ORDER BY dt;
指标口径速查（面试口答）

几个最容易被追问的口径

  • 留存：分母=注册用户数，分子=注册第 N 天仍活跃的去重用户；日期用 DATEDIFF 对齐。
  • 漏斗：数人用 COUNT(DISTINCT user_id)，不能按 step 分组。
  • 新老客：按用户首单时间分，ROW_NUMBER()=1 为首单。
  • 同比：LAG(gmv, 12) 取去年同月，需至少 13 个月数据。

窗口函数三个易错点

  • RANK vs DENSE_RANK vs ROW_NUMBER：并列是否跳号、是否拆开。
  • SUM OVER 默认 RANGE：逐行累加要显式写 ROWS BETWEEN ...。
  • WHERE vs HAVING：WHERE 过滤原始行，HAVING 过滤分组聚合结果。
